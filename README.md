# Installation du projet Symfony qui contient le framework CSS Tailwind et FLowbite

Pour installer le projet Symfony, vous devez faire la commande suivante : 

```shell
composer install
```

Une fois le projet Symfony installé, il faut installer les outils qui permettent à Tailwind et Flowbite de fonctionner.

C'est Node.js qui gère cette partie et donc vous devez faire la commande suivante : 

```shell
npm install
```

Une fois ces deux commandes exécutées et que tout est installé, vous continuez la configuration classique de votre projet.
